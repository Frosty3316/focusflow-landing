# FocusFlow 🚀

A modern landing page for a productivity-focused app concept.

## ✨ Overview
This project explores clean layout, typography, and motion design for a SaaS-style landing page.

## 🧠 Features
- Responsive hero section
- Subtle ambient background effects
- Feature cards with hover interactions
- Scroll cue for better UX

## 🛠️ Tech Stack
- HTML
- CSS
